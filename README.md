# Health Saathi — Android-focused PWA
Fresh project for Android phones including Samsung, Redmi, Realme and other Chromium-based Android browsers.
`index.html` contains the main UI, CSS and app logic. Keep `manifest.json`, `sw.js` and `assets/` stable.
PWA install/service-worker behavior requires HTTPS (GitHub Pages is suitable).
No external splash artwork URL is used.
Health metadata is local; photos use IndexedDB.
